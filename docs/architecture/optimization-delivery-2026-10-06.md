# 优化交付记录（2026-10-06）

本轮按用户授权落实项目审查中的主要问题。继续保持 Java 17、单 Maven 模块、模块化单体和 MySQL 库存权威来源，没有增加中间件用途、AI 写操作或人工补偿管理接口。提交范围包含本轮源码、迁移、测试、文档和一键验证脚本；本地凭据、构建产物与运行日志按 `.gitignore` 排除，原有文件和验收记录保留。

## 已落地

| 项目 | 最终行为 |
|---|---|
| 数量精度 | BigDecimal 在 JSON 和 OpenAPI 中统一为普通十进制字符串；采购、销售、调拨、盘点输入和编辑提交不经过 Number。四位小数与15位整数边界校验保留，零实盘合法，负流水可精确展示。ID、版本、分页计数仍为整数。 |
| 盘点恢复 | 未调整盘点可携带版本与原因取消，记录取消人/时间/原因，保留快照、实盘和审核证据，事务释放维度锁；不修改数量、不制造库存流水。已调整不可取消。提交/审核提前拒绝实盘低于冻结量，调整的最终校验保留。 |
| 管理员初始化 | 创建、ADMIN 绑定和审计在同一事务中，写入失败回滚；ADMIN 角色行锁协调并发初始化；规范化用户名，不提升已有同名用户权限。 |
| 安全库存预警 | 增加销售冻结/释放、调拨冻结/释放/目标收货和盘点调整六类 v1 事件。同步内部事件由 messaging 在原事务写 Outbox，避免模块循环；消息消费者继续读取 MySQL 最新可用量。 |
| Outbox 失败处理 | 区分网络失败与 Broker 确认后的持久化失败；后者抛出回滚，保留可重发消息。尝试、发布状态和关键发布轨迹影响行数异常不静默成功。 |
| AI 等待 | 默认整次预算90秒，每轮网络等待受剩余预算限制，工具前后检查预算；超限保留已有证据。前端提供取消等待和卸载中止请求，取消不弹系统错误、不回填迟到结果。 |
| 前端依赖 | 移除 Element Plus 全量注册，组件、指令与样式按页面引入，保留业务路由分块；同时明确实际表格行类型，未放宽 TypeScript 检查。 |
| 重复验证 | 新增 `scripts/verify.ps1`，集中执行后端测试/格式/打包、Compose 静态配置与前端全部检查；失败即停止，可选执行真实 MySQL/RabbitMQ 测试。 |

盘点取消复用 `INVENTORY_COUNT_WRITE`，允许 DRAFT、COUNTING、SUBMITTED、APPROVED → CANCELLED；所有取消必须写原因，和销售/调拨取消职责保持一致。新迁移 `V0.9.2` 扩展状态及取消审计 CHECK，没有修改历史迁移。详见 [库存规则](../business/inventory-rules.md) 和 [数据库说明](database.md)。

新增预警事件使用 `business.inventory.availability-changed.v1`，仍消费到既有预警队列。库存服务只依赖稳定的内部事件契约，监听器同步加入原事务，不通过 MQ 完成库存写入。既有采购/销售完成事件保留。详见 [消息运维](../operations/rabbitmq-reliability.md)。

- 真实登录隔离管理员，生产预览中的首页、采购和盘点页面正常加载。
- 盘点取消原因留空时仍停留确认框并提示原因必填；填写原因后状态为 CANCELLED，动作消失，只保留详情。
- 详情显示取消人、时间、真实原因和原账面量 `99999999999999.9999`；API再次核对余额未变。

## 部署与保留边界

- 数量响应由数字变为字符串，仓库内前端、OpenAPI和测试已同步；其他客户端应按字符串读取数量。合法旧数字输入仍可由后端解析，但新的客户端应提交字符串。
- 下次后端启动由 Flyway 自动执行 V0.9.2。本轮只迁移临时测试库，没有自动升级开发业务库，也没有修改开发数据库账号权限或原数据卷。
- AI_TOTAL_TIMEOUT 默认90秒，最大300秒。浏览器取消不保证立即终止同步 Servlet；已执行SQL也不会被硬中断。网络请求受剩余预算限制，超限不继续工具/模型轮次。
- Outbox仍在原事务内等待Broker确认；本轮修复失败恢复，没有引入事务外发送、认领租约或新的发布状态。是否进一步重构应有连接占用/积压实测依据。
- 真实模型、生产部署、迁移/运行账号隔离、完整Redis/MQ连接失败组合、全新Docker空数据卷初始化及性能压测仍未验证或未实施；未把局部验收写成所有场景通过。
- 临时浏览器页、前后端进程、浏览器测试库和RabbitMQ测试vhost已清理，RabbitMQ恢复为原先停止状态；MySQL和原有命名卷保留。
