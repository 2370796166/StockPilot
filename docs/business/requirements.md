# 产品范围

StockPilot 面向单企业、多仓库的中小型制造或电商业务，核心是采购入库、销售冻结与出库、库存流水、仓库间调拨和静态盘点的正确闭环。

## 已实现能力

| 能力 | 范围 |
|---|---|
| 基础资料 | 仓库、库位、单层分类、SKU、供应商；创建、查询、修改、启停，无删除接口 |
| 认证与权限 | BCrypt、JWT Access Token、实时数据库 RBAC、用户/角色/权限管理及基础审计 |
| 库存中心 | 仓库 + 库位 + SKU 余额、不可变流水；没有普通库存写接口 |
| 采购入库 | 草稿、提交、审核、完成；完成才增加实际/可用库存 |
| 销售出库 | 草稿、冻结、审核、完成；完成前可取消并释放冻结 |
| 多仓调拨 | 源仓冻结、调出、独立在途、目标收货 |
| 静态盘点 | 快照、维度锁、实盘、审核、差异调整 |
| 可选 Redis | SKU/仓库详情缓存，故障降级 MySQL |
| 可选 RabbitMQ | 完成事件 Outbox、重试、消费幂等、死信、低库存预警 |
| 可选只读 AI | 库存/单据/流水查询、来源追溯、受限时间区间汇总与当前冻结来源核对 |
| 管理后台 | 上述已开放接口的业务页面、权限菜单和路由，不展示虚构统计 |

## 默认角色

- `ADMIN`：管理员，拥有当前全部权限。
- `OPERATOR`：业务员，可读基础资料和库存，负责采购、销售、调拨、盘点的非审核动作。
- `AUDITOR`：审核员，可读相关资料、审计、库存和单据，负责业务审核。

当前 RBAC 为接口级权限，不含仓库级数据范围，也不强制制单人与审核人必须不同。

## 当前限制与范围外功能

- 单企业部署，不含多租户、批次、序列号、保质期或财务成本核算。
- 不支持部分入库、部分出库、部分调拨收货、调拨货损或退运。
- 采购没有拒绝/取消状态；静态盘点没有取消/退回路径，调整完成前维度锁持续存在。
- 没有 Refresh Token、单 Token 主动撤销、OAuth2/SSO 或 Redis 入口限流。
- 安全库存规则、预警和异步失败记录已有内部能力，但尚无管理 HTTP API/页面。
- AI 只有读取能力，没有自动制单、审核、库存调整、预测、补货、OCR、知识库或会话记忆；真实模型联调未验证。
- Compose 仅托管基础设施，不包含前后端应用容器；生产部署方案尚未提供。
- 测试覆盖范围见 [测试说明](../testing.md)，不据此承诺未经测量的性能或所有浏览器流程已验收。

数量、事务、幂等和状态机规则见 [库存规则](inventory-rules.md)。
